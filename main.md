# LLM Training Phases

Large Language Models (LLMs) are typically built in a sequence of phases, each one refining what the model knows and how it behaves.

> **Note:** these phases are a common blueprint, **not a mandatory recipe**. Every lab and team adapts, merges, reorders, or skips steps depending on their goals, data, and budget.

---

## Overview

| # | Phase | Goal | Data | Output |
|---|-------|------|------|--------|
| 1 | **Pre-Training (PT)** | Learn language, facts, and reasoning patterns | Massive raw text (web, books, code) | Base model |
| 2 | **Continued Pre-Training (CPT)** | Specialize in a domain or language | Domain-specific corpora (legal, medical, code, PT-BR, etc.) | Domain-adapted base model |
| 3 | **Supervised Fine-Tuning (SFT)** | Teach the model to follow instructions | Curated prompt → response pairs | Instruction-following model |
| 4 | **Alignment** | Match human preferences, safety, and style | Preference data, reward signals | Aligned assistant |

---

## 1. Pre-Training (PT)

The foundation. The model is trained from scratch on trillions of tokens using **next-token prediction**: given a sequence, predict what comes next.

- **Objective:** self-supervised language modeling
- **Scale:** the most expensive phase by far (compute, data, time)
- **Result:** a *base model* with broad world knowledge, but not yet a helpful assistant. It completes text rather than answering questions.

## 2. Continued Pre-Training (CPT)

Also called *domain-adaptive pre-training*. The base model keeps training with the same objective, but on a **focused corpus**.

- **Use cases:** new languages, specialized fields (law, medicine, finance), or code
- **Why it matters:** injects deep domain knowledge that SFT alone cannot add reliably
- **Watch out for:** *catastrophic forgetting*. Mixing in some general data helps preserve prior abilities.

## 3. Supervised Fine-Tuning (SFT)

The model learns **how to behave** by imitating high-quality examples of instructions and ideal responses.

- **Objective:** supervised learning on labeled prompt/response pairs
- **Result:** a model that follows instructions, holds conversations, and respects formats
- **Key insight:** data **quality beats quantity**. A few thousand excellent examples can outperform millions of noisy ones.

## 4. Alignment

The final polish. The model is steered toward outputs that humans **prefer**: helpful, honest, and harmless.

Common techniques:

- **RLHF**: Reinforcement Learning from Human Feedback
- **DPO**: Direct Preference Optimization
- **RLAIF / Constitutional methods**: feedback generated by AI guided by a set of principles
- **Verifiable-reward RL (RLVR)**: rewards from checkable outcomes such as math or code tests

---

## Evaluating Models: Benchmarks

How do we know if a model is actually good? We use **benchmarks**: standardized tests that measure abilities such as reasoning, knowledge, coding, math, and instruction following.

A few things to keep in mind:

- No single benchmark tells the whole story, so look at several.
- Scores can be inflated by **data contamination** (test data leaking into training).
- Real-world performance on *your* task is the ultimate test.
